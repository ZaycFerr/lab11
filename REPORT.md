# Лабораторная работа №11: Организация сеансов совместной разработки с использованием ngrok

## Цель работы
Изучение принципов совместной удаленной работы в терминале с помощью мультиплексора tmux и создание безопасных публичных туннелей к локальным сервисам (SSH) через платформу ngrok.

## Ход работы

1. Были настроены базовые переменные окружения и подготовлены рабочие директории для установки вспомогательного ПО.
2. В систему были интегрированы утилиты управления терминальными сессиями `tmux` и инструмент туннелирования `ngrok`.
3. С помощью команды `tmux new -s session_with_group` была создана общая сессия для совместного написания и отладки кода.
4. Проведена авторизация на платформе ngrok с использованием персонального токена:
